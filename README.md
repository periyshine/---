# 音频编辑器 - 声音素材剪辑和音效合成工具

一个基于 Web 的专业音频编辑和音效合成工具，使用纯 HTML、CSS 和 JavaScript 实现，无需任何后端服务。

## 功能特性

### 核心功能
- **音频导入**: 支持拖拽或文件选择导入音频文件
  - 支持格式: WAV, MP3, OGG, FLAC
  - 支持同时导入多个音频文件

### 播放控制
- ▶️ 播放 / ⏸️ 暂停 / ⏹️ 停止
- 🔁 循环播放
- 🔍 波形缩放（放大/缩小）
- 实时播放进度显示

### 音频编辑
- ✂️ 裁剪音频（指定开始/结束时间）
- 🔪 分割音频（在指定位置分割）
- 🔗 拼接音频（将多个片段连接）
- ↩️ 撤销 / ↪️ 重做操作
- 🎚️ 淡入/淡出效果
- 🔊 音频标准化
- 🔄 音频反转
- ✂️ 静音修剪

### 多轨混音
- ➕ 支持多音轨管理
- 🔈 每个音轨独立音量控制
- ⚖️ 声相控制（左右声道平衡）
- 🔇 静音/独奏功能
- 🎚️ 音轨混音

### 音频效果器
#### 均衡器 (EQ)
- 5段均衡器
- 低频 / 中低 / 中频 / 中高 / 高频
- ±12 dB 增益调节

#### 混响 (Reverb)
- 混响量控制
- 衰减时间调节

#### 延迟 (Delay)
- 延迟时间控制
- 反馈量调节
- 混合量控制

#### 压缩器 (Compressor)
- 阈值控制
- 比率调节
- 攻击/释放时间

#### 滤波器 (Filter)
- 低通 / 高通 / 带通 / 陷波
- 频率控制
- Q值调节

#### 失真 (Distortion)
- 驱动量控制
- 混合量调节

### 导出功能
- 💾 导出为 WAV 格式
- 可选采样率 (44.1/48/96 kHz)
- 可选位深度 (16/24/32 bit)

## 快速上手

### 1. 打开应用

在浏览器中打开 `index.html` 文件。

### 2. 导入音频

- 点击「导入音频」按钮选择文件
- 或直接将音频文件拖拽到导入区域

### 3. 编辑音频

- 裁剪: 选择波形区域，使用裁剪功能
- 分割: 在指定位置分割音频
- 添加音轨: 点击「添加音轨」按钮
- 调整音量: 使用音轨上的音量滑块

### 4. 应用效果器

- 在右侧效果器面板中启用所需效果
- 调整效果参数
- 实时预览效果

### 5. 导出音频

- 点击「导出」按钮
- 设置文件名和格式参数
- 点击「导出」下载文件

## 技术栈

- **HTML5**: 页面结构
- **CSS3**: 样式设计，深色专业主题
- **JavaScript (ES6+)**: 核心逻辑
- **Web Audio API**: 音频处理

## 架构设计

```
音效合成工具/
├── index.html              # 主页面
├── css/
│   └── style.css          # 样式文件
├── js/
│   ├── audio-engine.js    # 核心 Web Audio API 封装
│   ├── audio-editor.js    # 音频编辑功能
│   ├── effects.js         # 音频效果处理器
│   ├── mixer.js           # 多轨混音器
│   └── ui.js              # UI 交互控制
└── README.md              # 项目说明
```

### 核心类

- **AudioEngine**: 音频引擎，管理 AudioContext 和音频播放
- **WaveformVisualizer**: 波形可视化器
- **AudioEditor**: 音频编辑器，支持裁剪、分割、拼接等操作
- **TrackMixer**: 多轨混音器
- **EffectsProcessor**: 效果器处理器
- **UIController**: UI 控制器

## 快捷键

- **空格键**: 播放/暂停
- **Ctrl/Cmd + Z**: 撤销
- **Ctrl/Cmd + Shift + Z**: 重做
- **L**: 切换循环模式
- **Esc**: 停止播放

## 性能优化

- 使用 `requestAnimationFrame` 优化波形绘制
- 音频缓冲区复用减少内存分配
- 懒加载效果器节点

## 已知限制

1. **文件大小限制**: 浏览器对大文件的处理有限制，建议处理小于 100MB 的文件
2. **内存使用**: 处理大型音频文件会占用较多内存
3. **实时预览**: 某些效果器（混响）在实时预览时可能有轻微延迟
4. **导出格式**: 当前仅支持 WAV 格式导出

## 安全性

- 所有音频处理在浏览器本地完成，不会上传到服务器
- 不收集任何用户数据
- 文件仅在会话期间存储在内存中

## 故障排除

### 问题: 无法播放音频
**解决方案**: 确保先与页面交互（点击任意位置），浏览器要求用户交互后才能播放音频。

### 问题: 音频格式不支持
**解决方案**: 使用音频转换工具将文件转换为 WAV 或 MP3 格式。

### 问题: 导出后文件为空
**解决方案**: 确保至少有一个音轨包含音频内容，且该音轨未被静音。

### 问题: 效果器没有效果
**解决方案**: 检查效果器开关是否已启用，确保参数设置在合理范围内。
